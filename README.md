# Сайт Анны Когтевой — версия с интерактивным первым экраном

## Публикация на GitHub Pages
Загрузите **содержимое** архива в корень репозитория `anna-kogteva-site` (не сам ZIP). Файлы `index.html`, `styles.css`, `script.js`, `choices.js`, `config.js`, `.nojekyll` и папка `assets/` должны сохранить структуру. В GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Контакты Telegram и MAX хранятся в `config.js`. При выборе мессенджера клиент должен самостоятельно отправить сообщение; открытие чата не создаёт заявку. Квиз работает в браузере и не передаёт данные на сервер. Для передачи ответов клиент копирует их и отправляет в чат.

На первом экране семь направлений, анимацию можно остановить. Ниже сохранены разделы прежней версии сайта. Фото для кругов находятся в assets/circle-*.jpg.
